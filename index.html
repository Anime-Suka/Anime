Panduan Setup Web Server & Hosting Video

1. Penyimpanan File Video & Lokasi CDN (Cloudflare IP India PoPs)

Untuk mengoptimalkan pengiriman video streaming dengan latensi sangat rendah, disarankan menggunakan routing **Cloudflare Edge PoPs India** (Mumbai - BOM, Chennai - MAA, atau New Delhi - DEL):

  • Cloudflare Custom Host / Worker Proxy: Alihkan permintaan CDN video langsung melewati IP Edge Cloudflare kawasan India.
  • Cloudflare R2 Storage + India Edge Routing: Tanpa biaya bandwidth keluar (egress fees) dan terhubung langsung ke node terdekat.
  • Google Drive / Mega / Pixeldrain: Pilihan server mirror alternatif untuk unduhan publik.

2. Pemasangan Backend (Node.js & Express)

Jalankan server sederhana menggunakan Node.js jika ingin menyimpan database link video secara tersentral:

npm install express cors dotenv multer
